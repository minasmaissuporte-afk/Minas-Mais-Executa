---
name: Ranking regional de execução
description: Requisito do painel para exibir as lojas líderes por região no mês vigente.
---

O painel de análise deve apresentar as três lojas mais bem pontuadas de cada região, considerando o mês vigente.

**Why:** O usuário pediu um quadro padronizado para comparar os três primeiros colocados de cada região na pontuação de execução das tarefas do mês vigente.

**How to apply:** Agrupar pelo campo de região real da loja, usar a pontuação de execução já definida no produto e deixar o período analisado explícito.
